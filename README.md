# untouch

### Focus is hard. Untouch your phone

## React Native iOS App

This project uses Expo and React Native with TypeScript.

## Requirements

- Node.js (LTS recommended)
- Xcode and an iOS Simulator for local iOS development
- Expo Go on an iPhone for device testing

## Run on iOS

Install dependencies and start the iOS development workflow:

```sh
npm install
npm run ios
```

To start Metro manually, run `npm start`, then scan the QR code with Expo Go or press `i` to open the iOS Simulator.

For a native iOS build from Xcode, run `npx expo run:ios`. This generates the native iOS project and requires CocoaPods in addition to Xcode.
